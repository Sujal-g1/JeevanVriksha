# 🌿 JeevanVriksha – Rural Healthcare Management System

## 📌 Overview

JeevanVriksha is a digital healthcare management platform focused on improving healthcare delivery in rural areas, especially for **pregnant women and newborns**. It connects **ASHA workers**, **patients**, and the **system** into a single, easy-to-use platform that enables continuous monitoring, better record management, and timely intervention.

The core idea is simple: replace scattered, manual healthcare tracking with a **smart, digital, and accessible system** that works even for non-technical users.

---

## 🎯 What This Project Does

* Maintains **digital health records** for patients
* Helps ASHA workers **track, update, and monitor patients efficiently**
* Focuses on **maternal and newborn healthcare**
* Provides a **digital health card** for each patient
* Supports **multi-language interaction** for better accessibility
* Includes a **voice assistant** to help ASHA workers interact with the system easily
* Enables **structured and organized healthcare data tracking** instead of manual records

Overall, it transforms traditional healthcare workflows into a **digital, scalable, and user-friendly system**.

## 🧠 Design Philosophy

* Built for **real-world usability**, not just technical demonstration
* Focus on **simplicity over complexity**
* Designed keeping **non-technical users (ASHA workers)** in mind
* Emphasis on **clarity, accessibility, and efficiency**

---

## 🚧 Challenges Faced

### 1. Designing for Non-Technical Users

Creating a UI that ASHA workers can easily understand required multiple iterations and simplification of workflows.

### 2. Structuring Medical Data

Deciding how to store and organize patient data in a scalable and meaningful way was challenging.

### 3. Real-world Use Case Mapping

Translating real healthcare processes into a digital system required deep thinking about practical workflows.
